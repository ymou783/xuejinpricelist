# 分类首页与内容后台设计规格

按用户最新指示制作，代码同步 GitHub，用户自行部署到可运行 Node.js 的腾讯云服务器。根地址直接进入分类首页，后台地址 /admin。用户已上传的唯一海报放入基础体验单，使用 CDN WebP 供用户测速；另加入两条明确标记测试示例的同图副本，以便体验三图切换。其他海报、联系方式和福利细则等待补充，不沿用旧站报价或权益。

## 图像规格与文案锁

home-desktop.png / home-mobile.png 是前台主规格，category-empty.png 是内容窗口规格；admin-desktop.png / admin-mobile.png 是管理界面规格。实际查看 http://111.229.23.28:4017/ 后只借鉴「分类入口 → 内容窗口 → 图片放大」流程。

前台从上到下：雪烬电竞字标及价目表字样；轮播横幅（未填图片时显示三角洲价目表标题与冰焰）；搜索价目表；价目分类；趣味单上新 / 最近上新，来点新鲜玩法。；四个主分类基础体验单、趣味单、特色趣味单、陪玩单；联系客服 / 咨询与下单；预存福利 / 查看福利详情；老板权益；雪烬电竞 · 价目表；选择分类后可查看海报，点击海报放大。按用户最新截图删除原首页说明句。

空分类显示海报整理中 / 该分类的价目海报将在补充后展示。/ 返回分类。客服与福利分别显示客服信息待补充、福利内容待补充，不编造号码、二维码、优惠或支付流程。

后台顶栏：内容管理、查看网站、退出登录。六个分区：首页设置、首页轮播图、价目海报、联系客服、预存福利、老板权益。轮播图支持上传、CDN 路径、排序及删除；老板权益为独立标题和多行正文。海报编辑包含标题、分类、上传图片、已有 CDN 对象路径、宽高、上新、图片说明；支持新增、删除、排序、保存发布。登录界面是同系统的居中单表单：管理密码 / 登录后台，无默认密码。

## 视觉系统

- 色彩：冰蓝背景 #F3F7FE，纯白表面 #FFFFFF，深蓝文字 #15264B，次文字 #60749A，主色 #556BC4，边框 #CDDEFA。浅冰蓝背景光，不改为米白或粉色。
- 前台桌面 max-width 1312px；1536px 下左右 112px，顶栏 110px；轮播默认横幅至少 300px，标题最多 96px。四类横排、客服与福利两列。手机左右 20px、窄屏 16px；横幅至少 185px，标题 27–34px，主入口两列。长标题自动增加默认横幅高度。没有公告、虚假报价或统计。
- 标题用已有授权 Noto Sans SC Black 子集；普通文字用系统中文无衬线。手机分类 17px、说明 12–14px，后台输入 15–16px，最小触控目标 44px。
- 卡片白底细边、18px 圆角，轻蓝阴影；上新淡蓝横条。图标使用 2px 轮廓：自定义四尖星上新图标；lucide 的 Compass、Dice5、Gem、Headphones、MessageCircle、Gift、ChevronRight；空态 Image、导航 ArrowLeft/X。后台同一图标与按钮家族。
- 主视觉是单独生成的透明 ice-flame-source.png，编码优化为 WebP，不截取概念图、不加色罩；字标沿用真实品牌。悬停只轻微上浮；尊重减少动画偏好。
- 用户最新要求在原主视觉位置增加轮播图，因此将原冰焰作为默认单帧横幅放入同主题圆角细边容器；上传图片后按原比例完整显示。多图显示上一张、下一张、分页与暂停，单帧不显示无效控制。减少动画、页面隐藏、悬停和聚焦会停止自动切换。
- 老板权益放在辅助入口后、页脚前，标题含轮廓皇冠图标，内容为白底浅蓝细边面板。空态至少留出 150px（手机 130px）；未提供具体权益时仅显示「权益内容待补充」，不编造优惠或承诺。
- 管理端顶栏 80px；左导航 228px；主编辑区开放白色面板，海报列表与表单左右分列。手机导航横排滚动，表单单列，尺寸输入保留两列。

## 组件与功能

App 组合 Header、CategoryHome、ContentPanel、懒加载 ImageViewer。catalog 数据验证被 Node 服务与前台共用；useCatalog 加载内容；片段导航支持刷新、分享与浏览器返回。分类有多图时使用横向标题按钮，只请求当前图。大图支持缩放、复位、拖动、触屏滚动、Escape 和恢复焦点。

最新图片详情增加明确的标题（桌面23px／手机20px）与可见多行说明（桌面15px／手机14px），均位于图片上方；后台“图片说明”编辑公开description，图像alt独立保留。多图顶部使用同样白底蓝色的粘附切换区，显示第几张/共几张、上一张/下一张与横向标签。按用户最新截图，将标签字增至桌面18px／手机16px、加粗700，未选中文字加深；张数桌面16px／手机14px、加粗600。测试条目直接以名称与说明标注，仅用于布局测试。

搜索位于轮播下方、分类入口上方，使用白底蓝色细边圆角输入框，带可见标签与清空按钮。输入后在下方展示所有分类的匹配海报标题及分类，零结果、加载中、错误重试各有明确反馈。只匹配标题，关键词支持Unicode规范化、大小写与空格分词；不提前请求图片。结果链接使用#分类?item=海报ID，打开分类时直接选中目标海报；原#分类/海报ID放大链接仍可使用。

AdminApp 按需加载。服务端登录、HttpOnly 会话、CSRF 校验、限速、密码哈希、上传类型与尺寸校验。初始密码由部署者在服务器交互式设置，不写入源码。修改保存到可备份 data 目录，原子更新并检查版本冲突，重启保留。后台本地上传自动输出响应式 WebP；也可填写已上传 COS 的对象路径继续使用 EdgeOne。两种图片来源在界面与文档中讲清楚。

最新后台保存按栏目合并已发布内容，只校验和发布当前栏目，其他栏目草稿留在内存；取消也只还原当前栏目。未发布栏目有侧栏圆点和提示，切换栏目清除上一栏错误，保存或上传期间暂停切换。预存福利支持标题加正文、标题加图片或图文组合，新增后自动定位标题；上传复用现有实际图像校验与 WebP 处理。前台福利逐条展示，图片共用既有放大查看器，链接为#benefits/福利ID，Escape及浏览器返回恢复福利列表。老板权益保持文字编辑。

## 必要差异与验证

手机概念中的系统状态栏不绘制；图片生成的重字和拼写以文案锁为准。统一使用一张独立冰焰，避免手机重绘资产不一致。错误、加载、登录、已填内容、大图及复制反馈复用同一视觉系统。当前海报仅用户指定的一张真实图片及两条已标记的同图测试项，其余真实素材等待补充；不交付虚构报价或测试联系信息。

当前没有 Browser 插件或内置浏览器读取/点击工具，使用已安装的 Python Playwright + Chromium，直接 view_image 对照概念与实际截图，检查文案、层级、颜色、字重、图标、边距、主视觉及响应式。后台重点验证未登录保护、登录、上传、七入口编辑发布、持久化、退出、错误恢复。测试图片和账号不进入 GitHub。
