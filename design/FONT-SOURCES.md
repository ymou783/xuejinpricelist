# Display font

Noto Sans SC, Google Fonts, SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
The static 900-weight WOFF2 subset is renamed Snow Ashes Display and contains current UI characters; missing future characters fall back to system Chinese fonts. It is already included; normal builds do not download fonts.
