# 先配置图片 CDN，再制作价格表

图片在用户本地，多张合计约 100MB。先用 2–3 张代表图片打通链路，再批量上传。网站最终部署由用户完成。

## 1. 核对控制台资源

| 控制台 | 记录或检查 |
| --- | --- |
| COS 存储桶概览 | 完整桶名、地域、默认访问域名、访问权限 |
| 数据万象图片处理 | 同一个桶已开通图片处理；核对 WebP 功能开通情况和计费 |
| EdgeOne 站点 | 站点主域名、加速区域、站点状态、ZoneId |
| EdgeOne 域名管理 | 图片子域名、源站、CNAME、域名状态、HTTPS 证书状态 |
| 域名信息 | 是否已有 ICP 备案；大陆加速区域需要符合备案要求 |

不要提供 SecretKey、登录 Cookie 或访问令牌。截图中如果存在这些字段，请遮住。
打开浏览器不表示当前云端会话能读取标签页；没有浏览器工具时可提供截图或复制上述信息。

## 2. 连接 COS 与 EdgeOne

1. 使用现有桶，不必为接入 CDN 删除或重建存储桶。
2. EdgeOne 图片子域名的源站选择对应腾讯云 COS 桶，回源使用 HTTPS。
3. 私有桶配置 EdgeOne 私有 COS 回源授权，无需仅为接 CDN 把全部对象公开。
4. 按控制台提示验证归属、配置 CNAME 或完成已选择的 DNS 接入方式。修改前保留原记录。
5. 配置有效 HTTPS 证书，确认加速域名状态可用。
6. 使用 ?imageMogr2/... 时，查询字符串必须保留到源站并参与缓存键，不同处理参数不能共用缓存项。
7. 带内容哈希的图片可以长缓存；HTML 短缓存或不缓存。图片域名只提供可公开展示的素材。

a.jpg!thumb 形式的样式名在路径中，要保留该路径；查询字符串规则不是这种样式生效的唯一条件。
套餐价格、功能和计费以实际控制台为准。

## 3. 填写本地配置

将 config.example.json 复制为 config.local.json，只填写资源信息，不放密钥。

- region、bucket：实际 COS 地域和完整桶名。
- cdn_domain：图片加速域名，不含协议和路径。
- eo_zone_name 或 eo_zone_id：刷新工具使用的 EdgeOne 站点。
- local_image_dir：原始图片目录，默认项目根目录 images/。
- local_site_dir：网页构建产物目录，默认项目根目录 dist/，网页未制作时先保留默认。
- source_image_prefix：网页图片引用前缀；如网页用 images/a.jpg，填 images。
- cos_prefix：桶中的图片目录，可以与网页引用前缀不同。
- hash_filenames：默认开启。内容变化时生成新 URL，避免浏览器和 CDN 继续显示旧图。
- convert_webp、thumbnail_width：默认将适用的静态图片转 WebP，并缩放到 1200px 宽；以实际样图验证结果调整。

相对目录均相对于配置文件所在目录解析。GIF、SVG 等不自动套用静态图转码规则，避免影响动画或矢量用途。

## 4. 预览和上传

在项目根目录执行：

~~~bash
.venv/bin/python deploy-cdn/upload.py --dry-run
~~~

预览不访问腾讯云、不需要密钥、不写入映射表。
正式上传需要运行机器上已有的原始凭据环境变量 TENCENT_SECRET_ID 和 TENCENT_SECRET_KEY；
临时凭据还需要 TENCENT_SESSION_TOKEN。用本机安全的凭据管理方式设置，不写进仓库或聊天。
SDK 要在本地使用密钥签名，HTTPS 代理替换用的密钥占位符不能代替原始签名密钥。
也可以先在腾讯云控制台手工上传样图，无需向本会话提供密钥。

~~~bash
.venv/bin/python deploy-cdn/upload.py
~~~

全部成功后生成 url-map.json 和 url-map.csv。图片名包含内容哈希，重复上传按远端元数据跳过。
权限错误不会当成文件不存在。任意上传失败返回非零退出码，保留旧的完整映射表；
本轮之前已上传成功的对象不会自动删除。

## 5. 验证真实图片

使用映射表里的完整 cdn_url，或者控制台样图的加速 URL：

~~~bash
.venv/bin/python deploy-cdn/verify.py --url 'https://你的图片域名/images/实际图片.jpg?imageMogr2/format/webp/thumbnail/1200x'
~~~

检查真实 GET 响应、WebP 文件签名、连续两次请求的缓存证据和转换前后字节数。
退出码 0：图片访问、格式和缓存命中证据通过；2：图片可访问，但缓存命中尚未确认；1：请求或格式检查失败。
小图转码不一定变小，应结合真实样图判断。
没有真实域名和图片测试前，不把图片问题标为解决；单张测试也不能替代完整页面检查。

## 6. 图片通过后制作价格表

确认产品名称、分类、规格、价格、品牌和联系方式；缺少的内容待补，不编造真实价格。
网页直接使用 CDN 地址，并设置图片尺寸和首屏加载优先级，避免初次访问下载全部图片。
需要替换构建产物中的本地图片时：

~~~bash
.venv/bin/python deploy-cdn/rewrite-html.py --dry-run
.venv/bin/python deploy-cdn/rewrite-html.py
~~~

首张图片和显式高优先级图片保留立即加载，其余补懒加载，已有加载属性保留。
外部 URL 不重写，首次改动前保留 .bak 备份。只对网页构建目录使用，交付部署目录应排除 .bak 文件。

## 7. 需要时再刷新缓存

哈希命名通常无需刷新。必须刷新同名对象时，先预览指定目标：

~~~bash
.venv/bin/python deploy-cdn/purge.py --url 'https://你的图片域名/images/实际图片.jpg' --dry-run
~~~

去掉 --dry-run 才提交刷新，也支持互斥的 --prefix 或 --host。
CDN 刷新不能清除浏览器已有的长期缓存，图片更新优先使用新 URL。

验证只代表这一张样图，不表示后续所有图片或规则自动通过。
网站首版使用真实 CDN 图片，不需要运行改写脚本，也不需要部署时提供腾讯云密钥。
