# 雪烬电竞 · 三角洲价目表

打开网站即为分类首页。冰蓝色界面，适配手机和桌面，七个入口：基础体验单、趣味单、特色趣味单、陪玩单、趣味单上新、联系客服、预存福利。

后台位于 `/admin`，登录后可以新增、上传、分类、排序和删除海报，设置上新，修改首页文字、客服号码／链接／二维码，以及福利正文。点击「保存发布」后，前台刷新即可读取新内容。

每个栏目独立保存、独立取消；未完成的福利或海报草稿会留在对应栏目，不会阻止客服等其他栏目发布。侧栏圆点标记未发布修改，离开网站或退出时仍会提示所有未保存草稿。

「预存福利」点击「新增福利」，填写标题，再添加正文、图片或两者。支持 JPG／PNG／WebP 上传、替换、移除，自动优化图片并获取尺寸；前台显示福利标题、说明和可放大的图片。原有纯文字福利继续使用。首次更新此功能须同时更新 `src/catalog.ts`、`server/app.mjs` 和前端并重启 Node 服务；仅替换浏览器文件时，后台会提示尚未启用图片支持。

首页标题区域预留可配置轮播横幅，默认沿用冰焰画面；后台「首页轮播图」可上传、排序和删除图片，两张以上加载完成后每 5 秒切换，可手动翻页或暂停，悬停／聚焦时暂停，尊重系统减少动画设置。图片完整显示，不裁切图片中的文字。

轮播图下方提供「搜索价目表」，按全部分类中的海报标题实时匹配，支持部分关键词、多个关键词及英文大小写。点击结果会打开所属分类并选中对应海报，支持刷新、分享链接和浏览器返回。搜索不预加载海报图片；修改后台海报标题并发布后，前台重新读取内容即可搜索新标题。

分类入口下方、页脚上方保留「老板权益」区域，可在后台对应分区填写标题和多行正文。此内容与「预存福利」分别管理；未填写时仅显示待补充提示。原首页说明句已移除。

当前按用户要求在「基础体验单」加入已上传的一张真实海报，并增加两条名称和说明均标为测试示例的条目，暂时复用同一个图片文件，用于检查三图布局，不代表新增报价。图片使用 `img.xuejinclub.com` 的响应式 WebP 预览，原图仅在主动打开时下载；其他海报、轮播素材、联系方式及权益文案留待补充。不包含参考网站的价格、联系方式或权益。参考网站仅用于理解分类与图片查看交互。项目没有支付或订单系统。

## 本地开发

需要 **Node.js 24 或更新版本**（服务器通过 Node 原生 TypeScript 支持共享内容验证）。

```bash
npm ci
npm run admin:password
npm run dev
```

开发入口监听 `127.0.0.1:5173`，API 监听 `127.0.0.1:3001`；Vite 自动代理 API 和图片。管理密码至少 12 位，在终端输入且不回显，无默认账号密码。密码哈希保存到忽略的 `data/admin.json`。修改密码后重启服务，旧会话随之失效。

## 构建与服务器运行

```bash
npm run build
npm start
```

生产服务默认监听 `127.0.0.1:3000`。部署到腾讯云服务器的完整说明见 [DEPLOY.md](DEPLOY.md)，包括 Nginx、HTTPS、systemd、备份和升级。

仓库也提供 GitHub Pages 的前台预览工作流。使用时在 **Settings → Pages → Source** 选择 **GitHub Actions**，由工作流构建并发布 `dist/`，不要直接发布仓库根目录。Pages 不运行内容后台；完整后台仍需 Node.js 服务器。详见 [Pages 配置说明](DEPLOY.md#github-pages-前台预览)。

`npm run package` 同时生成纯静态前台包和包含后台的服务器部署包；后台需要 Node 服务，不能只将 HTML 上传到 COS 后使用。

## 图片来源

- **后台上传**：上传一张 15MB 以内的静态 JPG／PNG／WebP，服务器校验实际内容、去除元数据并生成多种尺寸的 WebP。图片保存在 `data/uploads/`，由本站服务器提供。此方式不需要腾讯云密钥，也不会自动上传 COS。
- **已有 COS 图片**：在编辑器填写对象路径（如 `images/文件名.jpg`）与原图宽高，图片继续经过 `img.xuejinclub.com` 的 EdgeOne／COS／数据万象链路。可修改全局图片域名。

首页按需加载当前轮播图与分类入口，不批量下载价目海报。打开分类时才请求当前海报的压缩预览；点击后打开可缩放查看器。浏览器后退、Escape、鼠标拖动、手机滚动、复制客服号码均可用。

每条海报的 `title` 和 `description` 会显示在图片上方，说明支持换行，与 `image.alt` 的替代文字分开。旧海报缺少 `description` 时以原图片说明填入，已有说明不会丢失。同一分类多张图片时显示总数、横向标签和上一张／下一张按钮；切换标题使用更大的加粗深蓝文字，每次显示当前图片，手机上标签可横向滑动。当前两个测试副本会复用浏览器缓存，只用于布局检查；请勿将其当作三张不同图片的流量测速。

## 数据与安全边界

`data/` 可通过 `DATA_DIR` 改到独立持久目录，必须备份且不会提交 GitHub。首次启动从 `public/catalog.json` 复制种子内容；后续以数据目录为准。上传文件删除海报后仍保留，以免误删其他引用，可在备份后手动清理。

公开配置中的 `banners` 为轮播图列表（`id`、`title`、`image`），`ownerRights` 为老板权益列表（`id`、`title`、`body`）。旧数据没有这两个字段时按空列表读取；保存时保留已有海报等内容并移除已停用的 `subtitle` 字段。

后台使用 scrypt 密码哈希、8 小时 HttpOnly／SameSite 会话、来源与 CSRF 校验、登录限速、上传格式与尺寸校验、原子保存和编辑版本冲突保护。会话保存在内存，重启后重新登录。生产使用 HTTPS；在受信任的本机 Nginx 后设置 `TRUST_PROXY=1`。

## 验证

```bash
npm run test:server
npm run build
```

服务端测试覆盖未登录保护、来源与 CSRF、密码和 Cookie、格式验证、并发版本冲突、真实图片转换、危险文件拒绝、持久化和退出。

浏览器通过 Playwright 验证六种宽度、七入口、后台编辑发布、图片上传与缩放、返回、焦点、复制和退出。正式内容与测试数据分开。
