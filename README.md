# 雪烬电竞 · 三角洲价目表

打开网站即为分类首页。冰蓝色界面，适配手机和桌面，七个入口：基础体验单、趣味单、特色趣味单、陪玩单、趣味单上新、联系客服、预存福利。

首页另有「武将介绍」入口。武将名册每页 6 位，宽屏三列、手机和窄窗口两列，支持昵称搜索、标签筛选、推荐筛选、页码跳转和返回定位。详情展示昵称、头像、标签、简介、擅长玩法、服务风格、须知及可选介绍图；头像与介绍图均可放大。推荐优先，其余沿用后台排序。每位武将有可分享的 `#warriors/ID` 链接，可复制咨询信息、查看已关联且仍在发布的价目海报、联系客服。

武将自助入口为 `/warrior`，首页页脚可进入；管理员在 `/admin` 的「武将管理」生成一次性邀请码（7 天有效），将邀请链接提供给武将。武将设置自己的账号密码，上传头像／介绍图片、填写资料、保存草稿并提交审核。账号名使用 3–32 位字母、数字、下划线或短横线，密码至少 12 位。武将仅能修改本人介绍，推荐、排序及关联价目表由管理员设置。管理员可退回并填写原因，或通过本次固定提交版本后发布。待审核时需撤回再修改；已有公开资料在新版本审核通过前继续展示旧版。两端均提供刷新审核资料／状态操作。

后台「武将管理」还提供资料状态筛选、逐张资料预览与编辑、跨页排序、发布／下架、邀请码撤销、账号停用／恢复及一次性密码重置链接（24 小时有效）。邀请码和重置码只存哈希；原始链接只在生成时显示。账号停用或密码更新后，原有武将登录立即失效。管理账号与武将账号、会话分别保存；武将不能访问其他人的草稿、待审核图片或管理员接口。

武将上传的图片先保存在受保护的 `data/warrior-private/`，自动读取尺寸、去除元数据并生成 WebP 多尺寸；审核前只有本人和管理员能预览。通过审核后，默认复制到本站公开上传目录，也可配置自动上传 COS，并使用原有 CDN 域名展示，见 [武将自助与 COS 部署配置](DEPLOY.md#武将自助入口与审核)。管理员的头像和介绍图仍支持直接上传及 CDN 对象路径自动读取尺寸。服务器收到 COS 上传错误时不会替换原发布资料。

四个分类与上新入口共用海报目录：每页 6 张，电脑宽屏三列两行，手机和窄窗口两列，按实际浏览器宽度自适应。支持在当前分类的全部海报标题中搜索、「全部／只看上新」筛选、上一页／下一页和页码跳转；保留后台发布顺序，不限制海报总数。卡片完整显示压缩缩略图、醒目标题、上新标记与可选说明，点击直接进入大图。

后台位于 `/admin`。价目海报采用海报库：服务端按标题／说明搜索，按四种分类、发布状态和上新筛选，显示缩略图与分类数量；每页固定显示 6 张，剩余海报通过上一页／下一页浏览。**海报总数没有固定上限**，分页仅控制每次显示的数量。其他栏目仍可修改首页、轮播、客服、福利和权益，点击「保存发布」后前台刷新即可读取。

海报可逐张「保存草稿」或「发布这张海报」。草稿允许暂缺图片、宽高或说明，保存在服务器，刷新后仍可继续编辑；已发布海报保存草稿时保留上次发布版本。只有发布成功的海报会出现在前台、上新与搜索结果中。下架保留草稿和旧发布内容，后续可以重新发布。

支持多选本地图片，或每行粘贴一条 CDN 对象路径批量添加；自动读取尺寸，标题按文件名生成并可修改，图片说明选填，分批导入为草稿。逐项显示失败原因，可单独重试、停止处理；稳定导入 ID 避免网络中断重试后重复添加。本次输入中的重复路径会合并。勾选本页后可批量更改分类、上新、发布、下架或删除，未完成条目单独列出。批量分类和上新只更新指定字段，其他编辑草稿需再次发布。

同分类、无其他筛选时可拖动同页海报排序，也可跨页指定分类内位置、移到顶部／末尾；复制海报会生成新草稿。排序会立即更新已发布海报顺序。分类中如有未发布的分类调整，先发布或通过批量分类确认后再排序，以保留其他分类的顺序。

其他栏目独立保存、独立取消；未完成的福利和权益编辑不会阻止客服或轮播发布，操作海报也不会阻止其他栏目保存。海报窗口未保存的编辑、其他栏目的未保存修改，在离开网站或退出时会提示；海报「保存草稿」后的内容已持久化。

「预存福利」和「老板权益」均可新增标题，再添加正文、图片或两者。支持 JPG／PNG／WebP 上传、替换、移除，自动优化图片并获取尺寸；原有纯文字内容继续使用。客服图片、福利图片和首页底部权益图片都可点击放大，共用缩放、拖动、滚动和返回操作。首次更新须同时更新完整 `src/`、`server/` 并重新构建、重启 Node 服务；仅替换浏览器文件时，后台会提示对应图片支持尚未启用。

「客服链接或说明」允许填写非网址文字。有效的 HTTP／HTTPS 网址显示为跳转入口，微信号、QQ号或其他文字直接展示。每条客服只保留「复制客服信息」：优先复制非网址的客服说明，未填说明或使用网址时复制联系号码／说明，网址跳转入口照常显示。首页页脚只保留品牌价目表标识，移除底部操作说明。

首页标题区域预留可配置轮播横幅，默认沿用冰焰画面；后台「首页轮播图」可上传、排序和删除图片，两张以上加载完成后每 5 秒切换，可手动翻页或暂停，悬停／聚焦时暂停，尊重系统减少动画设置。图片完整显示，不裁切图片中的文字。

轮播图下方提供「搜索价目表」，按全部分类中的海报标题实时匹配，支持部分关键词、多个关键词及英文大小写。点击结果直接打开对应海报的大图，关闭后定位到所属分类的对应页，支持刷新、分享链接和浏览器返回。搜索不预加载海报图片；修改后台海报标题并发布后，前台重新读取内容即可搜索新标题。

分类入口下方、页脚上方保留「老板权益」区域，可在后台对应分区填写标题、多行正文或图片。此内容与「预存福利」分别管理；未填写时仅显示待补充提示。原首页说明句已移除。

当前按用户要求在「基础体验单」加入已上传的一张真实海报，并增加两条名称和说明均标为测试示例的条目，暂时复用同一个图片文件，用于检查三图布局，不代表新增报价。图片使用 `img.xuejinclub.com` 的响应式 WebP 预览，原图仅在主动打开时下载；其他海报、轮播素材、联系方式及权益文案留待补充。不包含参考网站的价格、联系方式或权益。参考网站仅用于理解分类与图片查看交互。项目没有支付或订单系统。

## 本地开发

需要 **Node.js 24 或更新版本**（服务器通过 Node 原生 TypeScript 支持共享内容验证）。

```bash
npm ci
npm run admin:password
npm run dev
```

开发入口监听 `127.0.0.1:5173`，API 监听 `127.0.0.1:3001`；Vite 自动代理 API 和图片。管理密码至少 12 位，在终端输入且不回显，无默认账号密码。密码哈希保存到忽略的 `data/admin.json`。修改密码后重启服务，旧会话随之失效。

## 构建与服务器运行

```bash
npm run build
npm start
```

生产服务默认监听 `127.0.0.1:3000`。部署到腾讯云服务器的完整说明见 [DEPLOY.md](DEPLOY.md)，包括 Nginx、HTTPS、systemd、备份和升级。

仓库也提供 GitHub Pages 的前台预览工作流。使用时在 **Settings → Pages → Source** 选择 **GitHub Actions**，由工作流构建并发布 `dist/`，不要直接发布仓库根目录。Pages 不运行内容后台；完整后台仍需 Node.js 服务器。详见 [Pages 配置说明](DEPLOY.md#github-pages-前台预览)。

`npm run package` 同时生成纯静态前台包和包含后台的服务器部署包；后台需要 Node 服务，不能只将 HTML 上传到 COS 后使用。

## 图片来源

- **后台上传**：上传一张 15MB 以内的静态 JPG／PNG／WebP，服务器校验实际内容、去除元数据并生成多种尺寸的 WebP。图片保存在 `data/uploads/`，由本站服务器提供。此方式不需要腾讯云密钥，也不会自动上传 COS。
- **已有 COS 图片**：轮播图、价目海报、客服图片、预存福利、老板权益都提供「CDN 对象路径」输入框。填写对象路径（如 `images/文件名.jpg`）后自动读取原图宽高，图片继续经过 `img.xuejinclub.com` 的 EdgeOne／COS／数据万象链路。路径不含域名、开头的 `/` 或查询参数；全局图片域名在「首页设置」管理。

五处均保留直接上传选项。已有上传图片时，填入 CDN 路径即可切换来源；重新上传文件则切回服务器图片。更换 CDN 路径会清空旧尺寸，并在输入停顿后自动读取新原图的宽高；相同路径保留尺寸。五处均共用服务器尺寸接口，仅访问已保存的 CDN 域名，读取最多 256KiB 文件头识别静态 JPG／PNG／WebP，也处理 EXIF 旋转；读取失败会说明原因，支持重试或手动填写。旧请求不会覆盖新路径，正在手动填写的尺寸会保留。客服、福利和权益的可选图片可通过移除按钮或清空 CDN 路径移除，文案保留。上传文件的尺寸自动识别，保存图片来源后，预览及放大查看使用同一来源。

首页按需加载当前轮播图与分类入口，不批量下载价目海报。打开分类后仅为当前页最多 6 张海报请求 360／600px 的响应式 WebP 缩略图，其他页图片与大图按需加载；单张缩略图加载失败时可独立重试，不阻塞其他卡片。浏览器后退、Escape、鼠标拖动、手机滚动、复制客服信息均可用。

每条海报的 `title` 和 `description` 显示在目录卡片中，标题加粗，说明选填、支持换行，与 `image.alt` 的替代文字分开。较长说明在卡片中节选，可在大图的「图片说明」中展开阅读。明确保存为空字符串时不显示说明段落，发布与刷新后仍保持为空；图片替代文字继续自动生成。旧海报缺少 `description` 时以原图片说明填入，已有说明不会丢失。

大图查看器默认 50%，每次按 50 个百分点调整，可放大到 300%；恢复默认、重新打开和切换海报均回到 50%，继续支持拖动、滚动和打开原图。在当前搜索／筛选结果内可以上一张／下一张连续看图，电脑支持键盘左右方向键，Esc 关闭。关闭后保留关键词和筛选，回到当前海报所在页，标记「刚刚浏览」并恢复键盘焦点。搜索、筛选、页码及所选海报保存在链接中，刷新后可继续浏览；旧版 `#分类?item=海报ID` 链接仍可定位。当前两个测试副本会复用浏览器缓存，只用于布局检查；请勿将其当作三张不同图片的流量测速。

## 数据与安全边界

`data/` 可通过 `DATA_DIR` 改到独立持久目录，必须备份且不会提交 GitHub。首次启动从 `public/catalog.json` 复制种子内容；后续以数据目录为准。上传文件删除海报后仍保留，以免误删其他引用，可在备份后手动清理。

旧版海报首次编辑时自动迁移为「已发布」记录，保留原 ID、说明和顺序；迁移前将原 `catalog.json` 备份为 `catalog.json.before-poster-library.bak`。私有草稿与已发布快照一起原子保存在数据目录 `catalog.json` 的 `_posterLibrary`，不通过公开 `/catalog.json` 返回。其他栏目采用独立版本校验，海报保存采用逐张版本校验，多窗口竞争修改会明确提示。

公开配置中的 `banners` 为轮播图列表（`id`、`title`、`image`），`ownerRights` 为老板权益列表（`id`、`title`、`body`、可选 `image`）。旧数据没有这两个字段时按空列表读取；保存时保留已有海报等内容并移除已停用的 `subtitle` 字段。

后台使用 scrypt 密码哈希、8 小时 HttpOnly／SameSite 会话、来源与 CSRF 校验、登录限速、上传格式与尺寸校验、原子保存和编辑版本冲突保护。会话保存在内存，重启后重新登录。生产使用 HTTPS；在受信任的本机 Nginx 后设置 `TRUST_PROXY=1`。

武将账号、邀请码哈希、私有草稿及固定送审版本分别保存到数据文件的 `_warriorAccounts`、`_warriorInvites`、`_warriorLibrary`，不会出现在公开内容 JSON 中。首次升级编辑前备份 `catalog.json.before-warrior-library.bak`，旧数据缺少武将字段时按空目录兼容。私有目录、密码哈希和上传文件均随整个 `DATA_DIR` 备份，不能将此目录直接映射为静态网站。只公开 Node 服务提供的文件路径。

## 验证

```bash
npm run test:server
npm run build
```

服务端测试覆盖未登录保护、来源与 CSRF、密码和 Cookie、格式验证、并发版本冲突、真实图片转换、危险文件拒绝、持久化和退出。

浏览器通过 Playwright 验证六种宽度、七入口、后台编辑发布、图片上传与缩放、返回、焦点、复制和退出。正式内容与测试数据分开。
